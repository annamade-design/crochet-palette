# Contributing

Crochet Palette is in an early open-source stage. Please use an Issue to describe a bug or feature request before proposing a larger change.

- Keep each change focused and as small as practical.
- Do not rewrite the whole project without a clear, agreed reason.
- Verify existing functionality before and after your change.
- Do not add analytics, tracking, or external APIs unless a maintainer explicitly accepts them.
- Do not submit materials with unclear copyright, licence, or source provenance.

Feedback on accessibility, browser compatibility, and real crochet-planning workflows is especially welcome.
